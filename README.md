# FORMA — учебный каталог на DummyJSON

HTML, CSS и JavaScript без сборщика и собственного API. Каталог показывает фотографии, описание, цену, рейтинг и бренд. Поиск работает по названию, описанию и бренду; есть фильтр категорий и сортировка по цене и рейтингу.

## Запуск

```bash
python3 -m http.server 8000
```

Открыть http://localhost:8000/crud.html или использовать VS Code Live Server. Через `file://` браузер блокирует JS-модули. Для DummyJSON нужен интернет; ключ API не нужен.

## Возможности

- Нажатие на фото или основную часть карточки открывает модальное окно товара.
- Подробности содержат галерею, описание, все остальные полученные поля, характеристики, условия доставки, гарантии, возврата и отзывы.
- «Изменить» открывает большую форму: название, цена, описание, бренд, категория, остаток, рейтинг, скидка, главное фото, галерея, артикул, вес, гарантия, доставка, возврат и статус наличия.
- Создание использует такие же поля; обязательны название и цена. URL фотографий вводятся вручную, загрузка файлов не предусмотрена.
- Отзывы, размеры и служебные данные сохраняются при редактировании остальных полей.
- Удаление требует подтверждения. При ошибке API введённые поля и товары сохраняются.
- Диалоги закрываются кнопкой или Escape; во время запроса закрытие и повторная отправка блокируются.
- Интерфейс адаптирован под узкие экраны; для отсутствующих или недоступных фото есть заглушки.

## Fake API

Исходный код сервиса: https://github.com/Ovi/DummyJSON.
Документация: https://dummyjson.com/docs/products.
Данные загружаются с `dummyjson.com`, не из GitHub.

| Операция | Запрос |
| --- | --- |
| Получение всех товаров со всеми полями | `GET https://dummyjson.com/products?limit=0` |
| Добавление | `POST https://dummyjson.com/products/add` |
| Изменение существующего товара | `PUT https://dummyjson.com/products/{id}` |
| Удаление существующего товара | `DELETE https://dummyjson.com/products/{id}` |

DummyJSON имитирует изменения, но не сохраняет их на сервере. После успешного запроса меняется общий массив `app.products`. Перезагрузка возвращает исходный каталог. Повторный GET после изменения не выполняется.

Новым товарам выдаются уникальные отрицательные ID (`-1`, `-2`, …). Их изменение и удаление выполняются локально: сервер не хранит созданные записи. Для исходных положительных ID используются PUT и DELETE. Это учебный каталог без корзины и оформления заказов.

## Файлы и ответственность

Изначальную основу, API и Read сделал Алтынбек; Create — Нурдаулет; Update — Кана; Delete — Кыл. Затем интерфейс расширен общими карточками, подробностями и дополнительными полями.

| Файл | Назначение |
| --- | --- |
| `crud.html` | Страница каталога и контейнеры диалогов |
| `crud/styles.css` | Адаптивное оформление |
| `crud/api.js` | HTTP-запросы, таймаут 15 секунд, проверка списка |
| `crud/app.js` | Общий массив, загрузка, поиск, фильтрация, карточки, диалоги |
| `crud/details.js` | Фото, галерея и полный просмотр товара |
| `crud/fields.js` | Общие дополнительные поля форм и валидация |
| `crud/create.js` | Создание |
| `crud/edit.js` | Редактирование |
| `crud/delete.js` | Подтверждение и удаление |

Старые задания в `index.html`, `assignments.js`, `theme.js`, `cell-colors.js`, `color-count.js`, `sites/` к CRUD не относятся.

## Правила разработки

- Все товары находятся в `app.products`; модули получают `app` аргументом. Не импортировать `app.js` обратно в модули.
- Сохранять экспорты `initCreate(app)`, `initEdit(app)`, `initDelete(app)`.
- Запросы выполнять через `api.js`, менять список только после успеха.
- В обработчиках проверять `app.busy` и `app.ready`. Сбрасывать занятость в `finally`.
- Выводить полученные строки через `textContent`, заполнять формы через `value`. В `innerHTML` допускается только фиксированная разметка.
- Ссылки изображений допускают только HTTP/HTTPS.
- Название: 1–100 символов после trim. Цена: 0–1 000 000, максимум два десятичных знака. Рейтинг: 0–5; скидка: 0–100; остаток: целое неотрицательное число.
- Общие поля форм менять в `fields.js`. Отзывы и другие поля, не вошедшие в форму, не удалять из товара.

## Проверки

Node.js 22.7+:

```bash
node --test tests/*.test.mjs
```

Тесты используют подменённый fetch и проверяют API, редактирование, дополнительные поля, ошибки, блокировку повторных операций и удаление.

В браузере проверить загрузку, поиск, категории, сортировку, подробности и галерею; создание, редактирование исходного и нового товара, отмену и удаление; ошибку сети и повтор загрузки; работу Escape и клавиатуры; узкий экран. После перезагрузки должны возвращаться серверные данные.
